# تدقيق الاكتشاف العام — نبض بلس

## النطاق والقرار

يشمل هذا التدقيق **الصفحات العامة فقط**: الصفحة الرئيسية متعددة اللغات، وكتالوج معلومات الأدوية وواجهات تفاصيله الحالية المقيدة. تظل كل صفحات المريض وجلساته ومواعيده وطلباته وفحوصاته وملفه الصحي خارج الفهرسة، ولا تُنشأ أي صفحة قابلة للزحف من بيانات مريض أو نتائج أو تقارير أو أسعار.

## النتائج المرجعية

تشير إرشادات Google الحالية إلى أن أسس SEO التقنية والمحتوى الأصلي الموجه للبشر تظل الأساس للظهور في ميزات البحث التوليدية. لا توجد وسمية Schema خاصة للبحث التوليدي ولا ضمان لترتيب أو ظهور، كما أن إنتاج صفحات كثيرة متشابهة بغرض استهداف صيغ الاستعلامات يعد استراتيجية غير مناسبة وقد يخالف سياسة إساءة المحتوى الموسع.[1]

توضح Google أن `hreflang` يعرّف النسخ اللغوية للمحتوى نفسه ولا يحدد لغة الصفحة بدلاً من خوارزميات البحث؛ لذلك يجب أن تشير كل صفحة عامة مترجمة إلى المجموعة الكاملة من بدائلها، وأن تتضمن `x-default` لطلب اللغة غير المطابقة.[2]

| محور | قرار نبض بلس | الحد الأمني والمحتوى |
|---|---|---|
| البحث التوليدي | تحسين HTML المقدم من الخادم والعناوين وبنية المحتوى والروابط الداخلية للصفحات العامة. | لا ادعاء بتصدر أو توصية آلية أو توليد محتوى طبي آلي واسع النطاق. |
| تعدد اللغات | مراجعة بدائل `hreflang` الست و`x-default` وcanonical الذاتي للصفحات العامة فقط. | لا تعطى الصفحات الخاصة canonical أو بدائل لغات تجعلها قابلة للزحف. |
| البيانات المنظمة | تبقى `WebSite` و`MedicalOrganization` للصفحة الرئيسية فقط، ويظل كتالوج الأدوية المختلط `MedicalWebPage` و`noindex`. | لا `Drug` أو `Product` أو `Offer` ما لم يقدم Backend تصنيف نشر وحقولاً موثوقة وصريحة. |
| المحتوى | لا يضاف محتوى صحي إلا بعد مصدر طبي ومراجعة بشرية وهوية ناشر واضحة. | لا نصائح تشخيصية أو علاجية أو شهادات أو مراجعات مختلقة. |
| القياس | يراجع بعد النشر عبر Search Console وتقارير الأداء بوصفها مؤشرات. | لا وعود ترتيب ولا أدوات تعد بتلاعب في أنظمة الترتيب. |

## خطة التنفيذ

يفحص التنفيذ الصفحات العامة المسموح بها، الروابط الداخلية، `robots.txt`، `sitemap.xml`، بيانات JSON-LD، وبدائل اللغات. كل تعديل يرافقه اختبار HTML أو metadata، ولا يزيل `noindex` من الكتالوج المختلط أو من أي مسار خاص.
