# إتمام المرحلة 6 — الصيدلية والطلبات والوصفات ضمن العقود المنشورة

**الفرع:** `agent/web-complete-20260821`  
**رأس الدفعة:** `5df76796e74e150ea439082b8f778180f9015863`  
**التاريخ:** 22 أغسطس 2026

## النطاق المنفذ

تم توحيد أسطح القراءة في السلة، معاينة الدفع، قائمة الطلبات وتفاصيلها وتتبعها، كتالوج الأدوية وتفاصيله، وقائمة الوصفات. ركز التنفيذ على إظهار بيانات Sandbox المعتمدة فقط، وعلى حالات الفراغ والتعذر الصادقة، وعلى تباين وحركة ووصولية منسجمة مع نظام التصميم العالمي. كما أزيلت القيم المالية والكمية الافتراضية التي قد توحي بقيمة مصدرها غير متاح؛ يعرض النظام شرطة طويلة بدلاً منها، بينما تبقى قيمة الصفر ظاهرة فقط عندما تعيدها الخلفية صراحة.

| المسار | حالة التنفيذ | الحد الوظيفي المعتمد |
|---|---|---|
| `/[locale]/cart` و`/[locale]/cart/checkout` | قراءة محسنة ومختبرة | لا تعديل للسلة ولا إجراء دفع أو إتمام طلب. |
| `/[locale]/cart/prescription` | معاينة قراءة فقط | لا رفع وصفة أو إضافة للسلة أو إرسال. |
| `/[locale]/orders` و`/[locale]/orders/[orderId]` و`tracking` | قوائم وتفاصيل وتتبع قراءة فقط | لا إلغاء أو إعادة طلب أو تعديل للعنوان. |
| `/[locale]/medicines` و`/[locale]/medicines/[medicineId]` | كتالوج وتفاصيل منشورة للقراءة | لا شراء أو تسعير بديل أو تغيير سلة. |
| `/[locale]/prescriptions` | قائمة وصفات محدودة للقراءة | لا صرف أو تجديد أو إرسال. |
| `/[locale]/prescriptions/[prescriptionId]` | **محجوب صراحة** | منع عرض الجرعات والتعليمات من استجابة قائمة عامة حتى نشر `GET /prescriptions/{id}` المملوك والمصرح به. |

## قرار الحجب التعاقدي

تطلب حزمة العقود المرجعية إضافة `GET /prescriptions/{id}` بتفويض Bearer، وتحقيق ملكية، وDTO محدود للحقول المناسبة. لذلك أصبحت شاشة التفاصيل تعرض رسالة **«محجوب بانتظار عقد تفاصيل الوصفة المصرح به»** في اللغات الست بدلاً من إعادة استخدام قائمة الوصفات لإظهار معلومات حساسة. هذا يعالج فجوة مسار موجودة ويمنع توسيع نطاق بيانات غير متعاقد عليه.

## القرار المرحلي

تعد واجهات الصيدلية والطلبات **مكتملة ضمن عقود القراءة المنشورة** ومتحققة محلياً. تبقى كل عمليات الكتابة والدفع والإلغاء وإعادة الطلب والرفع والتجديد محجوبة بانتظار DTOs منشورة مع تحقق ملكية ومفاتيح Idempotency مناسبة.
