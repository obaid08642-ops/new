# بوابات جودة الإصدار — دفعة التحقق

**التاريخ:** 22 أغسطس 2026
**النطاق:** دفعة التحقق البصري متعدد اللغات، ودعم اتجاه بيانات الخادم المختلطة، وسهم انتقال المقالات بحسب اتجاه اللغة.

| البوابة | الأمر المنفذ | النتيجة |
|---|---|---|
| فحص الأنواع | `pnpm check` | ناجح؛ لا أخطاء TypeScript. |
| اختبارات الانحدار | `pnpm test` | ناجح: **104 ملفات اختبار ناجحة، 198 اختباراً ناجحاً، 23 متجاوزاً عمداً**. |
| بناء الإنتاج | `pnpm build` | ناجح باستخدام Next.js 16.3.1/Turbopack؛ اكتمل التجميع وفحص الأنواع وتوليد الصفحات. |
| سلامة الفروق | `git diff --check` | ناجح؛ لا مسافات بيضاء خاطئة. |

## نطاق التحقق

لا تشمل الدفعة أي عملية خادم أو معاملة صحية أو دفع. اقتصرت التغييرات السلوكية على عرض نصوص خادم مختلطة الاتجاه بشكل أصيل، واتجاه السهم البصري في قائمة مقالات الواجهة، وجميعها محمية باختبارات انحدار. نتائج المعاينة الحية المحلية ولقطاتها وبصماتها مسجلة في [`188_multilingual_visual_check_20260822.md`](./188_multilingual_visual_check_20260822.md).

> تحذير `pnpm` المتعلق بنقل إعدادات `pnpm.overrides` و`pnpm.patchedDependencies` إلى ملف workspace ليس فشل بوابة ولا يغير نتيجة البناء أو الاختبارات. يبقى بند صيانة منخفض الأولوية ولا يعالج داخل هذه الدفعة لتجنب تغيير بنية مدير الحزم بلا اختبار منفصل.
