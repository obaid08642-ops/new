# إتمام المرحلة 9 — الاختبارات والسيناريوهات

**التاريخ:** 22 أغسطس 2026  
**الفرع وقت التوثيق:** `agent/web-complete-20260821`

## تغطية محلية متحققة

أضيف اختبار `tests/translation-key-parity.test.ts` الذي يفرد شجرة مفاتيح الرسائل لكل من العربية والإنجليزية والأردية والهندية والبنغالية والفلبينية، ويمنع اختلاف مفاتيح الترجمات أو نسيان رسالة `Settings.sessionsSummary` في أي لغة. يبقى اختبار Express 5 الانحداري ضمن الحزمة لضمان عدم عودة مسار النجمة غير المتوافق.

آخر بوابة محلية كاملة بعد هذه الدفعة نجحت: `pnpm check`، و`pnpm test` بـ **104 ملفات ناجحة و196 اختباراً ناجحاً و23 متجاوزاً عمداً**، و`pnpm build` ناجح. تشمل الحزمة الموجودة اختبارات SSR، حدود الملكية المصدرية، عقود parsing، تصميم الواجهات، CSP/Proxy، وتراجع أحوال الفراغ والتوطين.

| مجال | وضع الاختبار |
|---|---|
| اللغات الست والـRTL | مسارات اللغة والاتجاه مغطاة، وأضيف تكافؤ مفاتيح الرسائل الكامل. |
| التصميم والوصولية | اختبارات انحدار رموز التصميم والبطاقات وحالات التركيز والحركة المقيدة للواجهات المحدثة. |
| عقود القراءة | اختبارات parsing وخوادم API وSSR موجودة لرحلات الرعاية والطلبات والصحة والمحتوى. |
| الأمن والجلسات | اختبارات Proxy وCSP وعدم تضمين الرمز واختبار توافق Express 5. |
| عمليات الكتابة | لا تُحاكى؛ تظل محجوبة إلى أن تصدر عقود OpenAPI ومفاتيح idempotency. |

## حالة Sandbox

تشغيل `RUN_SANDBOX_TESTS=true pnpm vitest run lib/api/sandbox-order-ownership.test.ts` في هذه الجلسة **لم ينفذ أي طلب شبكة**، لأنه توقف قبل تسجيل الدخول عند غياب `NABD_API_BASE_URL` من بيئة التنفيذ. لم تُخترع متغيرات أو حسابات بديلة ولم تُعدل الشفرة لتجاوز الحاجز. توجد نتائج تحقق Sandbox القراءة والملكية السابقة في أرشيف التدقيق، لكن هذه المحاولة الحالية لا تُحسب كنجاح جديد.

> **النتيجة:** بوابات الويب المحلية ناجحة، فيما إعادة تحقق Sandbox الحية في هذه الجلسة مؤجلة إلى حقن متغيرات البيئة المعتمدة للحسابين. لا يغيّر ذلك نتيجة اختبارات الويب المحلية ولا يتحول إلى ادعاء تحقق حي.
