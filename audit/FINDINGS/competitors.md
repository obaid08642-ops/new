## أولويات التنفيذ المقترحة (تأثير × جهد)
1. **P1**: طابور فوري + Today + سعر/انتظار معلن (استشارات)؛ موافقة تأمين مسبقة مدمجة (مختبر)
2. **P1**: Medfriend + تفاعلات + refill تلقائي مرتبط بالصرف (أدوية)
3. **P2**: موسوعة تحاليل + مفسر نتائج عربي + زر "احجز طبيب" من النتيجة الشاذة
4. **P2**: ملف عائلي طولي + تقرير PDF + مشاركة طبيب (مبني جزئياً — يُوسع)
5. **P3**: Shamel/Tabby + أكشاك + B2B مضمن + أندية مجتمع
