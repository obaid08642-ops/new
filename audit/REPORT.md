## 1. الملخص التنفيذي
- **الحجم المؤكد:** باكند 116 موديول/278 controller/1602 route (MongoDB فقط) · موبايل مريض 249 شاشة/6 لغات · ويب 270 صفحة/60 BFF · مزود 8 أدوار/41 شاشة · أدمن 51 صفحة · 117 spec + عقود E2E.
- **الخلاصة الصادقة:** المنصة حقيقية وواسعة (لا واجهات فارغة)، ونظيفة من المحتوى المزيف النشط، وأساسيات الأمن والمالية server-side موجودة. **لكن توجد 23 مسألة P0** (تدفقات مال/دفع مكسورة، تجاوزات، ثغرات إجرائية) **تمنع الإطلاق** قبل إصلاحها — كلها قابلة للإصلاح ضمن الخطة P3–P13.
- **لا شيء يُعاد بناؤه من الصفر.** الإصلاحات موضعية + إكمال + توحيد.

## 2. الخريطة المعمارية المؤكدة
```
تطبيق مريض (Expo57/router/Redux) ─┐
ويب مريض (Next16/BFF نحيف → NABD_API_BASE_URL) ─┼─→ NestJS API (/api/v1) ─→ MongoDB + Redis/BullMQ
تطبيق مزود (Expo54/navigation/zustand) ─┤         ├→ Socket.io/LiveKit → FCM/Expo push
أدمن (Next16 → BFF محروس → NestJS) ────┘         └→ Moyasar/Paymob/Tap/Stripe · S3/R2 · Gemini · SMS/FCM
أحداث: EventEmitter + domain_outbox + DLQ · مراقبة: Winston/Sentry/audit-logs · اختبارات: 117 spec + عقود
```
- مصدر الحقيقة: NestJS+MongoDB (لا MySQL حية — البقايا ميتة وتُحذف).
- الاستثناءات: `infra/fastapi` مهجور (يُحذف)، محفظة مكررة ×5 (تُوحد)، `compat/admin-spa` إلهية (تُفكك لاحقاً).
