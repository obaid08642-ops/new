## 5. مواصفة التأمين المعتمدة (نهائية — تحسم أي تعارض)
1. لا يوجد ولا يُبنى أي تكامل مع NPHIES أو شركات التأمين عبر منصتنا. أي stub/ادعاء تكامل مباشر يُزال/يُصحح.
2. بيانات التأمين من بروفايل المريض (الشركة/الفئة/الاسم) أو توجيهه لإكمالها قبل الطلب.
3. الطلب يصل المزوّد مع تفاصيل التأمين. المزوّد يحصل على الموافقة خارج منصتنا (بوابة نفيس/شركة التأمين).
4. المزوّد يرفع الرد عبر تطبيق المزوّد: موافقة/جزئية/رفض/انتظار + copay.
5. المريض يُخطَر → لا دفع قبل الرد → يدفع التحمل فقط → يتم الطلب. رفض = تحويل لكاش أو إلغاء.
6. نفس المعمارية: صيدلية/طبيب/مختبر/أشعة/تمريض. خصوصية قبل القبول.

## 6. البطاقة الذرية للشاشة (13 بنداً إلزامياً)

7 الحالات الأربع (Loading/Empty/Error/Success) 8 التنقل والروابط العميقة 9 الأداء (renders/قوائم/صور)
10 الأمان (tokens/logs) 11 الحكم (كامل/ناقص/مكسور) + الحالة الرسمية 12 تغطية اللغات الست للشاشة وديب لينكها
13 سلوك الشاشة عبر مصفوفة الأجهزة.
+ أسئلة القسوة لكل عقدة رحلة: انقطاع/انتهاء جلسة/رفض إذن/نفاد مخزون/فشل دفع/ضيف/لغة/دبل-تاب/رجوع أثناء الدفع.

## 7. الإضافات 18–23 (ملزمة)
- **18 تحسين الرحلات:** قياس خطوات كل رحلة + ترشيح الحذف/الضغط (7-8 شاشات→2-4) — صغير=مباشر، كبير=مقترح قبل/بعد + اعتماد المالك، بلا كسر منطق.
- **19 نظام التوثيق:** مجلد `audit/` هذا + PROGRESS.md حي + FINDINGS/ — تحديث بعد كل خطوة، أدلة file:line فقط.
- **20 الاختبار المزدوج:** اختبارات كل مرحلة (نطاق + regression) + منظومة P11 الكاملة.
- **21 Multilingual-Everything:** اللغات الست (عربي/إنجليزي/أردو/هندي/تغالوغ/بنغالي — عربي+أردو RTL) في: UI، ديب لينك موضعي بنفس Canonical ID + hreflang، SEO/JSON-LD/OG لكل لغة، Sitemap لكل لغة، GEO/AEO (llms.txt/FAQ/Speakable) لكل لغة، مخرجات MCP/AI والطلب عبر AI بكل لغة، ودجات/اقتباسات موضعية، إشعارات/أخطاء/إيميلات/ASO بكل لغة. بحث بنفس الاستعلام بـ 6 لغات → نفس الكيانات.
- **22 مصفوفة الأجهزة:** 320→4K، موبايل/تابلت/ديسكتوب، iOS/Android، أزرار ≥44pt، خطوط ديناميكية، Safe Areas، Portrait/Landscape، صور responsive — لكل التطبيقات والويب.
- **23 ألترا بريميوم ديزاين (P6-D):** استخراج Tokens → توحيد مصدر واحد → Benchmark عالمي (Apple Health/One Medical/Calm/Ada/Uber) → Micro-interactions/60fps/Skeletons/Haptics/Dark → ترقية مكوّن-بمكوّن بالتوازي → Visual regression.
