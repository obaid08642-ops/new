### Serious findings (ranked)
1. **1c01b92: Moyasar refunds after the first go to the wrong payment.** The breaker is cached by name and its function closes over the first `moyasarId`. The probe shows the 2nd refund POSTed to `pay_AAAA…/refunds` while `pay_BBBB` was marked refunded locally. Money and data-integrity bug on an admin route (`POST /moyasar/payments/:id/refund`). The local harness cannot catch it because fake_moyasar serves `/refund` and the backend calls `/refunds`.
2. **9537426: the guest-lifecycle job crashes at the second guest (E11000 on `email: null`).** Reproduced on a scratch DB with the same unique sparse indexes as nabd_live. If linkage is ever extended correctly it also hard-deletes guests whose lab/radiology/consultation bookings and payments then become orphaned. The "same as PdplService" claim is false.
3. **6ca29c4: kill-switch helper fails closed.** With FeatureFlagsService, an absent flag counts as "killed". Live has 0 flags, so wiring it as documented turns off AI, recommendations, search suggestions and the rest. The idempotency interceptor duplicates the global one and would 409 every keyed write if both were active.
4. **cffbab5: the load-shedding guard cannot be wired as documented** (Nest DI failure, proven). Its overload signal is a lifetime mean, and the heapUsed/heapTotal ratio would shed on normal V8 heap behaviour.
5. **X12 and most of 14.x are not done.** b20ecd3, 13f560c, 909fed4, 6ca29c4 and cffbab5 add helpers with zero callers and label the real work "deferred". AGENTS.md forbids deferring, and none of the deferred parts has a real external blocker except the owner-only steps: Cloudflare dashboard rules, TURN rotation, staging k6, hosted log storage.
6. 14.7: no route is publicly cacheable, `stale-if-error` is missing, and error responses carry no Cache-Control. X0's Docker-nginx CI leak test was never added.
7. bece53a claims "gitleaks on every PR" without touching CI. Its `.env.*` rule now ignores the tracked `*.env.production.example` templates. (The BRIEF's attribution of `expo install --check` to bece53a is wrong: it was 458c7b8.)
8. 59e0d6b strips GPS only on the multipart path. Base64 uploads (provider documents, image processor) and presigned uploads keep EXIF/GPS. There is no test.
9. No AGENT_PROGRESS entry for any of the 18 commits. Several commit messages make false claims: "batch" (a006d5a), "dead routes" (6f0a9a2), "same rule as PdplService" (9537426), "gitleaks on every PR" (bece53a).
