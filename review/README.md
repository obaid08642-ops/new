# كيفية مراجعة استعادة مصدر المزوّد

هذا الفرع يستعيد لقطة تنفيذ كانت محفوظة في أرشيفي المصدر بعد فقد بيانات Git المحلية قبل دفع الفرع السابق. لذلك لا تدّعي الالتزامات التاريخية السابقة أنها موجودة في المستودع البعيد؛ المرجع القابل للمراجعة الآن هو هذا الفرع والالتزام الذي ينشئه.

تُدار مصادر المشروع في `main` ضمن ملفي ZIP. ولتمكين مراجعة نصية واضحة بدلاً من مقارنة ملفين ثنائيين فقط، يحتوي هذا المجلد على فروق موحّدة مولدة مباشرةً بين أرشيفي `origin/main` والأرشيفين المستعادين في هذا الفرع.

| الملف | المحتوى |
|---|---|
| `provider-source-recovery.patch` | الفرق النصي بين محتوى `main:NabdProvider-provider.zip` وتطبيق المزوّد المستعاد. |
| `backend-source-recovery.patch` | الفرق النصي بين محتوى `main:nabdah-backend.zip` والخادم المستعاد. |

تُعد هذه الفروقات أدلة مراجعة مساعدة. يبقى المصدر المقرر للنشر هو `NabdProvider-provider.zip` و`nabdah-backend.zip` في جذر الفرع. لا تعتمد نتيجة الفروقات وحدها كإثبات تكامل حي؛ راجع تقرير التسليم وقائمة الـNO-GO قبل أي دمج أو نشر.
