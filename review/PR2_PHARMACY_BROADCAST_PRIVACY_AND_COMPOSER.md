# PR-2 — خصوصية البث ومؤلف العرض الخادمي

**الفرع:** `remediation/provider-production-governed`  
**حالة التسليم:** مراجعة فقط؛ **NO-MERGE / NO-DEPLOY**.

## النطاق والجذور

| الجذر | التغيير المحكوم |
|---|---|
| `PharmacyBroadcastService` | يعتمد الحساب الفعلي `provider_type=pharmacy` و`status in approved,active` قبل كشف البث؛ ثم يفرض عضوية `notified_pharmacies` لكل قائمة/تفاصيل/رفض. |
| DTO البث للمزوّد | يحذف `order` الخام واسم/هاتف/معرف المريض والعنوان والمرفقات، ويعرض فقط معرف البث/الطلب، الجولة والنطاق، ملخص الدفع، وبنود الدواء الأدنى. |
| `PharmacyOfferService.previewQuote` | يوفر معاينة خادمية للسعر والمخزون والكمية والبديل مع TTL 600 ثانية. لا يقبل السعر أو الرسوم أو ETA كسلطة. |
| سياسة التسليم | لا توجد سياسة خادمية منشورة في هذا المصدر؛ النتيجة صريحة `unavailable_read_only` ورسوم التسليم صفر من المصدر الخادمي، ولا تسمح الواجهة بتحديد option أو ETA أو fee. |
| `PharmacyDashboard` / `PharmacyBroadcastResponse` | بطاقة بث لا تعرض PII أو إجمالياً غير متاح. المؤلف يربط كل بند بعنصر كتالوج من `/provider/inventory/search`، ويدعم `available/unavailable/substitute` وكمية جزئية مقيدة بالمخزون ثم preview → draft → submit. |

## جدول صلاحية الوصول

| الطالب | قائمة البث | تفاصيل بث معلوم | بيانات محظورة |
|---|---|---|---|
| صيدلية معتمدة ومُخطَرَة | مسموح بDTO الأدنى فقط | مسموح بDTO الأدنى فقط | الهاتف، العنوان، المرفقات، الكائن order الخام، هوية المريض. |
| صيدلية معتمدة غير مُخطَرَة | لا ترى البث في القائمة | `403` | كل البيانات. |
| حساب pending أو doctor أو نوع مزود آخر | `403` قبل جلب البث | `403` قبل جلب البث | كل البيانات، بما فيها إمكانية تعداد المعرفات. |
| مريض أو معرف بلا حساب صيدلية فعّال | `403` | `403` | كل بيانات واجهة المزوّد. |

## جدول انتقال مؤلف العرض

| المرحلة | مصدر الحقيقة | ما يمنع الانتقال |
|---|---|---|
| ربط البند | عنصر inventory تابع للصيدلية | SKU غير مطابق أو بديل غير مصرح أو مخزون منتهٍ/غير متاح. |
| معاينة | الخادم يعيد الأسعار والكميات والإجمالي وTTL | عنصر ناقص أو قيمة عميل غير صالحة. |
| مسودة | نفس حساب المعاينة يعاد اشتقاقه خادمياً | لا تمر قيم price/fee/ETA/stock من العميل. |
| إرسال | المسودة غير منتهية والصيدلية مخوّلة | لا تخصيص ولا حجز نهائي قبل اختيار المريض. |

## الترحيل والتراجع والحدود

تضيف الدفعة حقلاً اختيارياً `fulfillment` في `pharmacy_offers`؛ لا يلزم backfill، والعروض القديمة تقرأ بقيمة `unavailable_read_only`. التراجع هو إعادة الحزم إلى commit السابق؛ لا توجد migration أو worker أو scheduler أو أمر تشغيل تلقائي.

لم يجرِ اختبار E2E حي مع MongoDB أو Redis أو PSP أو S3/R2 أو push أو جهاز Expo. لا يوجد في هذه الدفعة قرار أو تنفيذ لسياسة مناطق/رسوم/ETA تجارية؛ الواجهة تتوقف صراحة عند ذلك بدلاً من ادعاء قيمة أو نجاح تجاري.
