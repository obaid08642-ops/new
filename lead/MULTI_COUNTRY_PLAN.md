# Multi-country: execution plan (lead, 2026-11-17)
Inputs: lead/MULTI_COUNTRY_RESEARCH_2026-11-17.md (external research, 5 researchers), docs/platform/MULTI-COUNTRY.md (B's first code survey), the owner's design notes (global control plane + regional data planes, country != market != tenant != data region, versioned market configuration, snapshots on every order, licences per jurisdiction, global concept + market registration catalogue, audit-first).
Target (agreed): ONE platform (one patient app, one provider app, one web, one admin, one modular NestJS backend, one API contract) + MANY markets as configuration and policy, + HYBRID data: shared reference/config data, per-jurisdiction "data planes" (cells) for health/personal/order data only where law requires. Modular monolith, not microservices. Saudi Arabia becomes market #1 through the new model, not a special case in code. Existing journeys must not change (pharmacy broadcast + offers stays).

## Phase 2: Target architecture + ADRs (docs, owner approves)
