# فحص جاهزية تنفيذ العقود — 22 أغسطس 2026

## حالة نسخة العمل

تمت مزامنة نسخة العمل محلياً بعملية `fast-forward` فقط من دون دمج إلى `main`. صار الرأس المحلي والبعيد متطابقين عند:

```text
db404ee846832968a5cfa8c96d0d4101ad36efd0
```

ولم تسجل مساحة العمل أي تغييرات غير مدفوعة قبل عملية المزامنة أو بعدها.

## فحص العقود الحية

استُخدم العنوان الافتراضي العلني للويب `https://api.nabd.plus/api/v1` في طلبات قراءة فقط. لم يكن متغير `NABD_API_BASE_URL` محقوناً في بيئة التنفيذ. أُعيدت `404` من المسارات المرشحة التالية:

| مسار القراءة | HTTP |
|---|---:|
| `/openapi.json` | 404 |
| `/api-json` | 404 |
| `/docs-json` | 404 |
| `/swagger.json` | 404 |

لا يكفي وجود الحزمة المرجعية المحلية وحده لبدء تنفيذ mutations: يجب مطابقة DTOs وstatus codes وsecurity وidempotency مع OpenAPI للنشر الفعلي قبل إنشاء parser أو BFF أو واجهة. لذلك بقيت الدفعة 0/الهوية **محجوبة خارجياً**، ولم يُجر أي طلب كتابة أو تسجيل دخول أو استخدام حساب Sandbox.

## شرط الاستئناف الخارجي

يكفي أحد الأمرين التاليين لاستئناف التنفيذ فوراً:

1. رابط OpenAPI عام أو قابل للوصول من بيئة Sandbox، مع إشارة إلى commit/version النشر؛ أو
2. تعيين `NABD_API_BASE_URL` إلى Sandbox المنشور الجديد وإتاحة مسار specification الموثق.

عند توفر ذلك، تبدأ مقارنة العقد أولاً، ثم تنفذ دفعة الهوية فقط وفق بروتوكول success/failure/owner/replay قبل أي دفعة لاحقة.
