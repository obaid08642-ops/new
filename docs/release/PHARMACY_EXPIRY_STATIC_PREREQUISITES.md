# انتهاء عروض وبث الصيدلية — الحزمة الساكنة فقط

> لا تسجل هذه الحزمة scheduler أو worker أو Redis أو cron، ولا تنفذ migration. يقتصر نطاقها على نموذج المجال، الأمر الخادمي المقيّد، وسجل التدقيق والـoutbox واختباراته.

## الأمر الحاكم

```ts
expireDuePharmacyOffers(now, cursor, limit)
```

يقبل الأمر وقتاً صريحاً وcursor وحداً أقصى لا يتجاوز 200. يحصل على lease Mongo باسم ثابت قبل المسح؛ فإذا وجد تشغيلاً آخر يعيد نتيجة `concurrent_run` بلا تعديل. تسير العروض والبث بترتيب `id`، ويعاد cursor صالح للاستئناف. تنتهي فقط العروض ذات الحالة `open` والمنتهية، وتغلق فقط البثوث المفتوحة المنتهية التي لم يرتبط طلبها بعرض مختار أو حالة دفع أو تأمين.

| الكيان | الانتقال | أثر الأمر |
|---|---|---|
| عرض مفتوح منتهٍ | `open → expired` | يكتب سبباً ووقتاً ونسخة، ثم يضيف audit وoutbox قابلين للتكرار. |
| claim اختيار عالق | `selection_pending → open/expired` | يستعيد claim بعد انتهاء مدته؛ لا يمس عرضاً اختير بالفعل. |
| بث مفتوح منتهٍ بلا عروض | `ORDER_BROADCASTING → AUTO_CANCELLED` ثم `open → closed` | انتقال حاكم وسجل فقط؛ لا إعادة مخزون أو إلغاء دفعة أو إخطار. |
| بث منتهٍ وعروضه جاهزة | `open → closed` | لا يغير الطلب ولا العروض، لتبقى خيارات المريض الصالحة مستقلة. |
| طلب مختار أو دفع/تأمين | لا انتقال | يحفظ كما هو؛ له timeout وسياسة منفصلان لاحقاً. |

## الترحيل والتراجع

يوجد artifact قابل للتشغيل اليدوي في `backend/migrations/20260827_pharmacy_expiry_static.mjs`. ينشئ فقط indexes للبحث، dedupe وlease؛ لا يقوم بـbackfill ولا يمس طلباً أو عرضاً أو معاملة قائمة. يجب قبل تشغيل `up` أخذ backup، تجربة `up/down` على نسخة معقمة، وإحصاء indexes. يستدعى `down` لحذف **الفهارس الجديدة بالاسم فقط**؛ لا يحذف أي سجل audit أو outbox، لأن سجلات التدقيق لا تمحى ضمن rollback.

## حدود الاختبار

اختبارات الوحدة تغطي انتهاء عرض، الاستئناف بعد restart من artifact pending، فوز اختيار متزامن، حماية العرض المختار/الدفع/التأمين من انتهاء البث، ورفض تشغيل موازٍ عبر lease. لا تغطي الحزمة Mongo replica-set transaction، استرداد crash في منتصف اختيار يحجز مخزوناً، PSP، نشر VPS، أو مراقبة worker/scheduler. لا يجوز اعتبار ذلك جاهزية إنتاج أو E2E.
