# Copy Style Guide

## Core Principles

**benefit before feature** — Lead with the user value, not the functionality.

**one idea per section, with 1–3 bullets** — Keep sections focused and scannable.

**specific headlines** — Avoid vague wording; be precise.

**short, scannable paragraphs** — One concept per paragraph; keep it concise.

**a clear CTA = verb + outcome** — e.g., "اطلب الآن ويصلك اليوم" (Order now and it'll arrive today).

**answer objections before the CTA** — Address delivery time, licensed pharmacist, refund, insurance upfront.

**proof next to every claim** — Ratings count, license number, delivery time from real data.

**the first screen says what it is, the price and how fast** — Immediate clarity on value proposition.

**write to one person** — Speak directly to the target user, not a generic audience.

## Per-Locale Banned Phrases (Do Not Use)

### Arabic (ar)
- Superlative medical claims (e.g., "الأفضل", "الأسرع بدون منافس")
- Generic openers (e.g., "في عالمنا هذا", "في زمننا هذا")
- Em dashes, aphorisms, "not X but Y" formulas

### English (en)
- "Best in class", "leading", " cutting-edge"
- Generic openings like "In today's world"
- Em dashes as sentence connectors
- "Not X but Y" structures

### Urdu (ur)
- Similar banned patterns as Arabic/English adapted to Urdu conventions
- Avoid fabricated claims and generic openings

## Length Limits Per Component

| Component | Max Characters (ar) | Max Characters (en) | Max Characters (ur) |
|-----------|--------------------|--------------------|--------------------|
| Hero headline | 20 | 25 | 20 |
| Sub-headline | 80 | 100 | 80 |
| Body paragraph | 300 | 350 | 300 |
| CTA text | 50 | 50 | 50 |
| Benefit bullet | 100 | 120 | 100 |

## Review Workflow

1. **Content author** writes copy following the guide
2. **Owner review** approves key pages (home, product, doctor, service, checkout, onboarding, notifications, emails)
3. **CI lint** runs banned-phrase check and length validation per locale
4. **Publish** only after all gates pass

## Localized CTA Formula

**Verb + Outcome** (Arabic): `اطلب الآن ويصلك اليوم`
**Verb + Outcome** (English): "Order now and receive today"
**Verb + Outcome** (Urdu): " Order now and it will arrive today"

## Prohibited Patterns Across All Locales

- Fabricated or superlative medical claims (SFDA guidelines)
- Generic openers that don't convey specific value
- Em dashes used as sentence connectors
- "Not X but Y" formula structures
- Vague superlatives without evidence
