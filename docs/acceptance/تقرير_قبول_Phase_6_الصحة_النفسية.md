## الملخص التنفيذي

أعيدت صياغة وحدة الصحة النفسية لتكون **تسجيلَ دعمٍ ذاتي** بدلاً من تدفق تشخيصي. أصبحت واجهة المزاج تسجل ما يختاره المريض فقط، مع تفاصيل اختيارية مضبوطة، وتقرأ السجل المملوك له فقط من واجهة API الفعلية. أزيلت الحسابات التي تصنّف الاكتئاب أو القلق أو الضغط إلى شدة سريرية، وأغلقت شاشة التقييم الذاتي التشخيصية ومسار المطابقة المدّعى بالذكاء الاصطناعي بتحويلات صادقة إلى تدفقات قائمة بالفعل.

تتضمن شاشة **المساعدة العاجلة** الآن تحذيراً صريحاً بأن نَبْض ليس خدمة أزمات، وزراً لاتصال الطوارئ المحلية، ورابطاً مباشراً للاستشارة داخل نَبْض، ورقم 937 بوصفه **استشارة صحية في السعودية** لا خدمة أزمة؛ تؤكد وزارة الصحة السعودية أن 937 يوفّر استشارات صحية على مدار الساعة.[1]

## ما نُفّذ

| المجال | التنفيذ المقبول |
|---|---|
| عقد سجل المزاج | `POST /mental-health/mood` يتحقق من قيمة المزاج، والمقاييس الاختيارية 1–5، وساعات النوم 0–24، والملاحظة حتى 500 حرف، وحتى 8 وسوم فريدة. لا تُضاف طاقة أو ضغط أو نوم أو تفسير سريري لم يرسله المريض. |
| الملكية والأمن | كل عمليات المزاج وجهات المساعدة تقيد الاستعلام والإنشاء والحذف بـ`patient_id` المستخرج من JWT. أزيل مسار `guest` من متحكم الصحة النفسية. |
| الإحصاء الوصفي | يعيد ملخص المزاج متوسطات وصفية أو `null` عند غياب البيانات؛ لا يعيد رسائل مطمئنة أو تسميات اكتئاب/قلق/شدة. |
| التقييمات التشخيصية | أزيل `SelfAssessment` ومخزنه وتسجيله داخل الوحدة ومسارات `POST/GET /mental-health/assessment`، وألغيت منطق PHQ-9/GAD-7/PSS والتفسير السريري. |
| واجهة المزاج | شاشة جديدة لتحديد المزاج، وتفاصيل اختيارية، ووسوم دلالية، وملاحظة قصيرة، وحالات تحميل ونجاح وفشل وفراغ؛ تستخدم `GET/POST /mental-health/mood` فقط. |
| المساعدة العاجلة | شاشة تصعيد تعرض رسالة سلامة غير ملتبسة، وزر اتصال بالطوارئ المحلية، و937 في السعودية، وتدفق الاستشارات، وجهات الاتصال الشخصية التي يضيفها المريض ويسترجعها `GET /mental-health/crisis-contacts`. |
| المحتوى غير الجاهز | حُوّلت شاشات التقييم الذاتي، ومطابقة المعالج بالذكاء الاصطناعي، والتأمل، والتنفس إلى تحويلات صادقة، لأن المحتوى السابق لم يكن مترجماً بالكامل أو كان يتضمن إحصاءات/ادعاءات غير موثقة. |
| اللغات | أُنشئ قاموس `mental-health.ts` صريح للغات: العربية، الإنجليزية، الأردية، الهندية، البنغالية، والفلبينية، مع اختبار تطابق المفاتيح. |
| النسخ الاحتياطية | حُفظت الواجهة والخدمة والمتحكم والمخطط السابقة في `backups/mental-health-pre-phase6/`. |

## حدود السلامة التي أصبحت مطبقة

> سجل المزاج **ليس تشخيصاً** ولا يقدّم توصية علاجية أو تعديل دواء. عند خطر مباشر، توجّه الشاشة إلى الطوارئ المحلية أو أقرب قسم طوارئ، ولا تعرض تمرين تنفس أو نص تهدئة بوصفه بديلاً عن الاستجابة العاجلة.

| قرار | التطبيق العملي |
|---|---|
| لا تشخيص نهائي | أزيلت `Severity` و`AssessmentType` والتفسير النصي للمقاييس السريرية من خدمة ومخطط ووحدة الصحة النفسية. |
| لا بيانات وهمية | لا توجد سجلات سابقة أو إحصاءات ثابتة أو أهداف يومية في الواجهة الجديدة؛ شاشة السجل تعرض ناتج API فقط. |
| لا أرقام مساعدة غير موثقة من الخلفية | الخلفية لم تعد تلحق أرقاماً إقليمية ثابتة بقائمة المستخدم؛ تعرض جهات الاتصال التي أنشأها المريض فقط. 937 معروض في الواجهة بوصفه استشارة صحية سعودية موثقة. |
| تصعيد مناسب | زر الطوارئ وزر الاستشارة منفصلان وواضحان، مع تفسير أن التطبيق ليس خدمة أزمة. |
