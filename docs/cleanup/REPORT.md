# Code cleanup before the final deploy (2026-10-25)

Method: `knip` per app for unused files, exports and dependencies, then a manual check of every candidate (grep for imports,
config files, scripts, CI workflows, Dockerfiles, acceptance and live suites). Only what was confirmed unused is removed; anything
uncertain stays and is listed below. Migrations, deploy files, seed/data files and `tools/ops` are out of scope.

## patient-web (this PR)
- **Leftovers of the first AI build (Manus template):** `vite.config.ts` (a Manus debug-log Vite plugin; the app builds with Next,
  tests with `vitest.config.ts`), its plugins (`@builder.io/vite-plugin-jsx-loc`, `vite-plugin-manus-runtime`, `@tailwindcss/vite`,
  `@vitejs/plugin-react`), the Manus sandbox host in `next.config.ts` `allowedDevOrigins`, the `wouter` patch, and the `@shared` /
  `@assets` test aliases to folders that do not exist.
- **70 unused dependencies** (no import anywhere in the app, its configs or scripts): the Vite/wouter/tRPC/Express template stack,
  31 Radix UI packages, react-query, react-hook-form, framer-motion, axios, date-fns, sonner, vaul, cmdk, Tailwind/PostCSS,
  AWS S3 SDK, and others. The lockfile shrinks by about 3,800 lines.
- **15 dead files** with no importer: `components/premium-icons.tsx`, `components-next/{header-cart-badge,link-button,
  mobile-bottom-nav,premium-health-illustration,profile-edit-form,vector-illustrations}` (+ their CSS modules and one test of a dead
  component), `lib/api/{mental-health-server,prescriptions-detail}.ts`, two orphan CSS modules.
- **Kept on purpose** although knip lists them: the acceptance suites and `appointment-booking-form` (run by
  `vitest.acceptance.config.ts`), `scripts/*` (sandbox contract runners), `public/sw.js` (served), `server/*.d.mts`,
  `components-next/ui-generated/index.ts` (generated by `tools/design/sync-ui-components.mjs`), and the 205 unused exports and 243 unused
  types (left for a later pass; removing exports one by one is low value and high churn right before a deploy).

Checks: `tsc --noEmit` 0 errors, `vitest run` 348 files / 2202 tests passed, `next build` succeeded.
