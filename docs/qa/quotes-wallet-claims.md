## Every write to a wallet balance (grep, 2026-11-01)
- `collection('wallets')`: written only in `common/wallet-ledger.ts` (find, create-if-missing upsert, and `$set` of the ledger sum). `admin-crm.controller.ts:89,91` only reads.
- The `Wallet` Mongoose model: injected only in `nabd-extensions` (`walletModel`), where `processWalletTransaction` no longer uses it to write.
- `wallet_transactions`: read by `finance-suite.service.ts`, `admin-crm.controller.ts`, `admin-disputes.controller.ts`, `pdpl.service.ts` and `orders.service.ts` (legacy fallback read); written only by `postWalletEntry`.
- `compat/admin-spa.module.ts:691` `$inc: { balance: points }` is the **loyalty points** account (`loyalty_accounts`), not `wallets`. Points are not money; its award path and `loyalty.service.ts` keep a transaction row and a duplicate check, the admin adjust has no idempotency key (left, see below).

## Not done, and why
- **Cart bars before a provider is chosen** (app `(tabs)/diagnostics.tsx` `tabTotal`, web legacy `diagnostics-cart-client.tsx`) still add catalogue prices. No binding total exists before a provider is picked; the server's answer is the basket's `from_price`, so the label has to become "from" (a wording and layout change: Design). The legacy web chain also needs the `d-31` decision.
- **Consultation:** the app confirm screen shows no amount before the gateway, the web booking page shows the doctor's fee. The quote endpoint is there for Design to put the total on both.
- **Loyalty points** (`admin-spa.module.ts` `adjust`, `loyalty.service.ts`) change a points balance with `$inc` next to a transaction row; the award path checks for a duplicate, the admin adjust has no idempotency key. Points, not money; not changed.
- **`backend/openapi.json`** not regenerated (the generator needs the database); the build does it.

## For the owner (money policy, not code)
