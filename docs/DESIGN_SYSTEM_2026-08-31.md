# نظام التصميم الموحد Nabd — 2026-08-31
المصدر البصري (مراجع المستخدم): أيقونات فيكتور بريميوم ثلاثية الأبعاد ناعمة، أنيميشن متقن،
اللون الأساسي أخضر ليموني (المرجع 4)، وألوان فرعية نعناعي/أصفر/مرجاني/كحلي (المرجعان الأخيران).

## القواعد
- الخلفية الأساسية: أوف-وايت/رمادي فاتح `#F5F5F7` (بأسلوب iPhone) والبطاقات بيضاء — لا خلفيات ملوّنة.
- كل شاشة جديدة/مدمجة في المريض والمزود والويب تستهلك `src/theme/brand.ts` (موبايل) — وتُرحَّل نفس القيم للويب لاحقاً.
- الأيقونات: فيكتور بريميوم بأسلوب 3D ناعم (ظل خفيف + تدرج)، لا صور مسطحة.
- الأنيميشن: قيم `motion` الموحدة (fast/base/slow + spring) — انتقالات وظيفية لا زخرفية.
- الألوان الدلالية: lime=إجراء رئيسي، mint=نجاح/صحة، yellow=تنبيه لطيف/عروض، coral=إجراء بارز/خصم، navy=نص/داكن، sky=معلومات.
- RTL أولاً، تباين AA كحد أدنى.
