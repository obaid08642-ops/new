# بوابة الأمن — طبقة الاكتشاف العام

## النطاق والقرار

يغطي هذا التدقيق الصفحة الرئيسية العامة `/ar` و`/en`، و`robots.txt` و`sitemap.xml`، ومسار الكتالوج العام المقيد. لا يفتح التدقيق أي مسار مريض، ولا يغيّر بيانات الخلفية، ولا يضيف endpoint متصفحياً يحمل Bearer token.

| محور | الضابط المنفذ | نتيجة المراجعة |
|---|---|---|
| الجلسة | صفحات المريض تبقى خلف `requirePatientAccess` وcookies httpOnly؛ مسار الكتالوج العام لا يستقبل أو يرسل توكن مريض | ناجح |
| BOLA/IDOR | لا يعتمد المحتوى العام على `patientId` أو `userId` أو معرف طلب/حجز؛ صفحات التفاصيل الخاصة لا تدخل sitemap | ناجح |
| الخصوصية | محلل الكتالوج يعرض الاسم/المادة/الشكل/التركيز فقط ويستبعد السعر وبيانات المريض | ناجح باختبار SSR |
| الفهرسة | `robots.txt` يحجب API والمسارات الخاصة؛ HTML الخاص يرث `noindex` | ناجح، مع بقاء حماية الجلسة هي الحاجز الفعلي |
| الكتالوج المختلط | العناصر غير الدوائية تمنع استعمال `Drug` و`MedicalWebPage` وفهرسة تفاصيل الكتالوج | ناجح، فجوة G-SEO-002 مفتوحة في الخلفية |
| مدخلات البحث | حد طول الاستعلام 80 حرفاً، الصفحة 1–100، والجلب من خادم فقط | ناجح |

## الأدلة المنفذة

| التحقق | النتيجة |
|---|---|
| `pnpm check` | ناجح |
| `pnpm test` | 39 ملفاً ناجحاً، 58 اختباراً ناجحاً؛ اختبارات Sandbox منفصلة عن التشغيل المحلي |
| `pnpm build` | ناجح؛ `robots.txt` و`sitemap.xml` static routes |
| اختبار SSR الكتالوج | السعر و`patient_id` لا يظهران في HTML أو JSON-LD |
| اختبار policy | sitemap يحوي `/ar` و`/en` فقط، ويستبعد المسارات الخاصة والكتالوج المختلط |
| تحقق HTTP | `/ar` يخرج `index, follow`؛ `/ar/medicine-catalog` يخرج `noindex, nofollow` |
| تحقق بصري | لوحة الهاتف لتسجيل الدخول تعرض الحقول والزر ضمن العرض بعد إصلاح RTL |

## قيود متعمدة وفجوات

لا يعتمد `robots.txt` وحده لمنع الوصول أو تسرب البيانات؛ فهو إشارة زحف فقط. تظل كل بيانات المريض خلف BFF والتفويض الخلفي. لا تدرج صفحات تفاصيل الكتالوج في sitemap ولا تمنح `Drug` JSON-LD إلى أن يسلم Backend عقد نشر وتصنيف دوائي موثقاً كما في `backend-handoff-phase-5.md`.

## قرار البوابة

يُسمح بالصفحتين العامتين الرئيسيتين فقط في sitemap الحالية. يبقى الكتالوج العام متاحاً للقراءة وموسوماً `noindex`؛ فلا يجوز اعتباره صفحة دواء عامة أو استخدامه في أي ادعاء SEO/GEO حتى يغلق G-SEO-002 باختبارات عقدية جديدة.
