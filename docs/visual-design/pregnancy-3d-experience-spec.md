# مواصفات تجربة تطور الجنين ثلاثية الأبعاد — نَبْض

## الهدف

إنشاء تجربة حمل بصرية فاخرة تعرض المرحلة الصحيحة من تطور الجنين تلقائياً بحسب ملف الحمل، مع حرية استكشاف جميع الأسابيع. التجربة تعليمية وعاطفية ومريحة بصرياً، وليست تصويراً طبياً فردياً أو أداة تشخيصية.

> **قاعدة المحتوى:** كل مرئية تمثل تطوراً تعليمياً نموذجياً فقط. لا تمثل صورة سونار أو جنين المستخدمة، ولا تحدد سلامة الحمل أو حجمه أو جنسه أو وضعه.

## التفاعل الأساسي

| الحالة | السلوك المطلوب |
|---|---|
| ملف حمل فعّال | حساب الأسبوع من `last_period_date` أو `due_date` وعرضه تلقائياً عند فتح الشاشة. |
| لا يوجد ملف حمل | لا تعرض جنيناً افتراضياً؛ وجّه المستخدم إلى إعداد متابعة الحمل. |
| الأسبوع الحالي | علامة «أسبوعك الآن» وصورة 2D مرجعية ونموذج 3D مرتبط بالمرحلة ووصف قصير. |
| استكشاف يدوي | شريط زمني 1–40، وسهمان السابق/التالي، وزر للعودة إلى أسبوع المستخدم. |
| وضع 3D | تدوير أفقي سلس، تكبير محدود، إعادة ضبط المنظور، ومؤشرات أجزاء تعليمية اختيارية. |
| وضع 2D | مرئية أسبوعية أصلية، تكبير محدود، ولا يدّعي قابلية الدوران. |

## اللغة البصرية

يجب أن تكون المرئيات واقعية طبياً بأسلوب ناعم، لا فوتوغرافية مرعبة ولا كرتونية. الخلفية عبارة عن تدرج لؤلؤي دافئ من الوردي الغباري والخوخي والعاجي، مع إضاءة حجمية ناعمة وبيئة رحمية تجريدية غير دموية. لا تُستخدم مشاهد دم أو أعضاء مكشوفة أو تفاصيل جراحية أو إيحاءات لحالة صحية.

| عنصر | قاعدة التنفيذ |
|---|---|
| الجنين | هيئة متناسبة مع المرحلة، جلد أو غشاء ناعم بحسب التطور، ملامح هادئة وغير مبالغ فيها. |
| الحبل السري/المشيمة | يظهران بشكل مبسط وتعليمي عند ملاءمة المرحلة، بلا واقعية صادمة. |
| الخلفية | مساحة هادئة موحّدة الأسلوب، لا نص مولّد داخل الصورة. |
| القياس | لا تعرض أرقاماً داخل الصورة؛ الأرقام تعرض في مكوّنات تطبيق قابلة للترجمة. |
| التنوع | تبقى المرئيات تعليمية ومحايدة؛ لا تدّعي تحديد هوية أو عِرق أو جنس مستخدم. |

## مصفوفة المراحل الأربعين

| الأسابيع | المشهد البصري المميز | مرحلة النمو في نموذج 3D |
|---|---|---|
| 1–2 | اندماج خلايا وبداية مبكرة تجريدية دقيقة جداً | كرة/بلاستوسيست تعليمي، لا شكل جنين مكتمل. |
| 3–4 | انغراس وتكوين مبكر في بيئة لؤلؤية | قرص/جنين مبكر مبسّط. |
| 5–6 | انحناءة جنين أولية وبراعم أطراف | رأس أكبر وجذع منحني وبراعم دقيقة. |
| 7–8 | شكل جنيني مبكر واضح وأطراف قصيرة | نمو الأطراف والملامح الأولية. |
| 9–10 | هيئة جنين صغيرة بملامح لطيفة | أطراف وأصابع أولية متناسقة. |
| 11–12 | انتقال بصري إلى جنين أكثر وضوحاً | نسب رأس/جذع مبكرة. |
| 13–16 | بداية الثلث الثاني وحركة لطيفة | جسم ممدود وأطراف أدق. |
| 17–20 | نمو واضح ومرحلة حركة تعليمية | تحسن النسب والتفاصيل السطحية. |
| 21–24 | جنين في وضعية ملتفة هادئة | ملمح أكثر امتلاءً وتفاصيل أطراف. |
| 25–28 | نمو الثلث الثالث المبكر | زيادة الامتلاء والحجم. |
| 29–32 | هيئة جنين متطورة بالكامل تقريباً | استدارة ونمو ملحوظ. |
| 33–36 | وضعية استعداد للولادة | وضعية رأس لأسفل كمشهد تعليمي اختياري. |
| 37–40 | جنين مكتمل بملامح هادئة | نموذج مكتمل، لا يدّعي وزن/وضع المستخدم الفردي. |

كل أسبوع داخل المجموعة يختلف فعلاً في الحجم والنسب والوضعية والإضاءة والتكوين، ولا يعتمد على تغيير رقم أو خلفية فقط.

## بطاقات المحتوى الأسبوعي

| البطاقة | طول المحتوى | حد السلامة |
|---|---|---|
| «ما يتغير هذا الأسبوع» | جملة أو جملتان تعليميتان | مراجعة علمية، بلا تنبؤ فردي. |
| «عناية عامة» | نص قصير عن نمط عام مثل الماء أو الوجبات المتوازنة أو الراحة | لا خطة علاج أو جرعة مكمل أو حمية شخصية. |
| «تواصلي مع مقدم الرعاية» | يظهر عند موضوع حساس أو قرب الولادة | لا يقيس حالة طوارئ من البيانات وحدها. |
| «أسبوعك الآن» | وسم سياقي | يتطلب ملف حمل فعلياً. |

## أمثلة صياغة عامة حسب الثلث

| المرحلة | الصياغة المقترحة |
|---|---|
| 1–13 | «اختاري وجبات متوازنة واشربي الماء بانتظام. ناقشي احتياجاتك الخاصة ومكملاتك مع مقدم الرعاية.» |
| 14–27 | «استمري في التنوع الغذائي واتبعي إرشادات فريق الرعاية المتابع لحملك.» |
| 28–40 | «استمري في الراحة والتغذية المنتظمة، وراجعي فريق الرعاية عند أي تغير يقلقك أو يقلق حركة الجنين.» |

## متطلبات النموذج ثلاثي الأبعاد

1. النموذج محلي داخل التطبيق، وليس رابط Sketchfab أو مورد WebView خارجي.
2. ملف/ملفات `GLB` مضغوطة ومقسمة بحسب مراحل الأسبوع، مع بيانات وضعية وتحول لكل أسبوع.
3. دعم اللمس: دوران أفقي، ميل رأسي محدود، تكبير محدود، وإعادة ضبط.
4. استخدام نقاط اختيارية قليلة مثل الرأس والذراع والقدم في المراحل المتأخرة؛ لا تعرض تسميات لا تنطبق على المراحل المبكرة.
5. الأداء المستهدف: تحميل تدريجي، ملصق 2D فوري، ثم ظهور 3D عند الجاهزية.
6. لا تستخدم أصلاً من منافس أو نموذجاً بلا ترخيص صالح للتوزيع التجاري.

## معايير القبول

* يوجد 40 ملف مرئي 2D أصلياً مختلفاً ومتسقاً.
* يوجد تمثيل 3D متغير حقاً مع الأسبوع، لا نموذج واحد ثابت لكل الأسابيع.
* لا شاشة سوداء ولا اعتماد على رابط نموذج خارجي.
* يظهر أسبوع المستخدم تلقائياً فقط عند وجود ملف حمل.
* يمكن استعراض الأسابيع الأخرى بلا تغيير بيانات المستخدم.
* جميع النصوص الظاهرة مدعومة باللغات الست.
* كل محتوى طبي إرشادي ومراجع قبل الإطلاق، ولا يستخدم كتشخيص أو متابعة لحالة فردية.
