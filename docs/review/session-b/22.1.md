# 22.1 Repeat and refill: built

Supersedes the BLOCKED note of commit d706d84d1. The owner answered both questions:

- A refill is an ordinary pharmacy order from the same path as any order: create, then submit (so it is broadcast to pharmacies). No payment logic of its own; no prices are copied.
- Prescription validity (expiry date and remaining refill count) is read only from the prescription record on the server. Expired or used up returns 409.

**Endpoint:** `POST /patient/pharmacy/orders/:id/refill` (`@RequireIdempotency()`), in `PatientPharmacyController`, calling `PharmacyRefillService.refill`.

**Order of work:**
1. Source order must be this patient's (404 otherwise). An order with no items is a 409.
2. Catalogue flags decide whether a prescription is needed (never client flags).
3. For a prescription line: the order must carry `prescription_id`; the record must exist for this patient (404); `valid_until` and `refills_remaining` must be set (409 `prescription_validity_unknown`); expired (409 `prescription_expired`); no refills left (409 `prescription_refills_exhausted`).
4. The draft is created through `PharmacyOrderService.create`.
5. One refill is taken with a conditional update (`refills_remaining >= 1` and `valid_until > now`). If it loses, the draft is cancelled and the 409 is returned.
6. `PharmacyOrderService.submit` broadcasts the draft.
7. If submit fails while the order is still a draft, the draft is cancelled and the refill given back. If the order already went out, the refill stays used.

**Open questions (answer on this PR):**
- Nothing on `main` writes `valid_until` or `refills_remaining` yet. Until a writer exists, every prescription refill returns `prescription_validity_unknown`. Who sets them (prescriber, pharmacist, or an admin tool)?
- A prescription sent as an attachment (`prescription_attachments`) has no record, so it cannot be refilled (409 `prescription_required`). Is that the intended rule?
- The refill copies `insurance_policy_id` without checking that the policy is still active. Should a refill check it?
