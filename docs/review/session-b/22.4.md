# 22.4 Delivery promise: BLOCKED (needs owner decisions; partly built on main)

Checked on `main` (bab83c422 and later), 2026-10-18.

**Already on main**
- Pharmacy offers carry `eta_minutes` and a delivery option (`pharmacy-offer.service.ts`), but the patient-facing `approx_delivery` is always `null` (`pharmacy-offer.service.ts` ~544).
- Collection proof for cash on delivery (`pharmacy-allocation.service.ts` ~487–507, `delivery.collection_proof`). It records the amount, not that the patient received the goods.
- Legacy dispatch is disabled: `legacy_order_dispatch_disabled_delivery_proof_required` (`pharmacy.controllers.ts` ~150). The proof rule is already named in code and has no implementation.

**Missing on main**
1. ETA by location on product pages: no zone or distance model; no ETA source except the pharmacy's own `eta_minutes`.
2. Delivery slots: no slot model for pharmacies or couriers.
3. Live courier tracking on a map: no courier location feed or storage (no `courier_location`, no lat/lng on allocations).
4. Proof of delivery (photo or code given to the courier): no field and no flow; the disabled path above is where it belongs.
5. Cold-chain flag on items: no field on medicines, orders or the courier flow.

**Why it is blocked**
- Items 1–3 need a product decision: who sets the zones and slots (pharmacy or platform), and whether the courier app sends live location (a new endpoint and privacy rule).
- Item 4 changes the delivery flow (who can mark an order delivered, and what the code is). That is business logic the owner has to choose: photo, code, or both.
- Item 5 needs the list of cold-chain medicines from the pharmacist.

**Questions for the owner (answer on this PR)**
1. ETA and slots: set by each pharmacy, or by the platform per zone? Is the ETA shown before the order (estimate) or only after the pharmacy accepts?
2. Live tracking: may the courier app send its location while an order is out for delivery, and for how long is it kept?
3. Proof of delivery: a photo, a 4-digit code the patient gives the courier, or both? Who may confirm the delivery?
4. Cold chain: which medicines, supplied by whom (the pharmacist's list)?

Build order once answered: (4) and (5) first (small, server-side), then (1) and (2) with the slot model, then (3) with the courier feed.
