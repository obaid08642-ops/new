# patient-web walkthrough (issue #1550), 2026-10-23

## Method
`tools/live/web_walkthrough.py` crawls every route in `web_walkthrough_routes.json`, signed-out and signed-in, in six locales, at 360/390/768/1280, light and dark. It flags HTTP errors, console errors, untranslated text (`english_text`/`arabic_text`), sign-in walls and axe violations (`AXE=1`). `web_click_sweep.py` follows every link and presses every safe button (spend/send/destroy buttons are skipped). Each fix PR has a journey `tools/live/j_web_*.py` that is red on main and green on the branch.
