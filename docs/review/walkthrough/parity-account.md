# Parity audit: account and sign-in (patient-web vs patient-app vs boards)

Screens compared: /welcome, /login, /register, /otp, /forgot-password, /password-reset (app /reset-password), onboarding (language, intro), / and /dashboard (home), /search, /notifications, /profile, /profile/addresses, /profile/edit, /settings, /settings/language, /settings/notifications, /settings/security. No wallet or payment-method screen exists in the app or the web, so none is compared.
Gap count by class: missing 22, different 10, wrong 0, illogical 2, broken 3 (total 37).
Boards used: AuthWeb, Auth (welcome), HomeWeb, HomeApp, SearchWeb, Notifications, Account, Settings. Login, Register and Otp boards are 500-byte stubs that load Auth.dc.html, so those three are compared with AuthWeb and the app.
