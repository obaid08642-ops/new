## Needs review

| Route | Element | Kind | Note |
|---|---|---|---|
| `/orders/[orderId]/tracking` | GET /orders/:id/tracking | backend | Reads the legacy orders collection only: a pharmacy order (pharmacy_orders) always 404s. The app's deep link orders/:id/tracking and any other client of it need the pharmacy order instead. |
| `/orders/[orderId]/tracking` | Live map, courier position, vehicle | backend | A pharmacy order carries no courier location or vehicle (only courier name, phone and the eta the pharmacy typed); the board's map is not drawn. |
| `/orders/[orderId]/tracking` | Pharmacy name | backend | GET /patient/pharmacy/orders/:id has no pharmacy name (allocations hold only pharmacy_account_id; the offers list drops expired offers), so the board's pharmacy row cannot be drawn. |
| `/orders/[orderId]` | Reorder through /orders/:id/reorder | backend | The legacy reorder and reorder-partial refuse pharmacy orders (503 canonical_pharmacy_flow_required); the web reorders through the cart. The BFF route app/api/orders/[orderId]/reorder is now unused by any screen. |
| `/pharmacy/reorder` | Prescription flag of a line | backend | Order items carry no rx flag and no price. Lines are marked as needing a prescription when the order has a prescription_id, so checkout asks again; a line-level flag would be exact. |
| `/orders` | Orders of other services | owner | The board lists any service (home lab test); the app merges appointments, labs, radiology, nursing, claims and returns. The web page lists pharmacy orders only: the owner decides whether the web order centre is unified (needs a unified endpoint or six reads). |
| `/delivery/address-select` | Entry points | client | No web screen links here (the cart's address card and checkout go to /profile/addresses); the page is reachable by address only. Link it from the address card's Change, or retire it. |
| `/delivery/address-select` | PATCH /users/me/addresses/:id | backend | Answers 200 with null for an unknown id and has no ownership error; the client treats only a returned address with is_default true as saved. |
| `/orders` | List has no governed_state | backend | GET /patient/pharmacy/orders returns raw documents without governed_state; list actions are chosen by status and the order router reads the detail. |
