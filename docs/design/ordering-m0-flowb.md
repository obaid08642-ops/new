# Ordering M0 boards: flowb (spec section 6 items 6-11)

Each board holds app light 390, app dark 390 and web light 1280 side by side, with extra stacked state frames, built with the same components as Ord01-Ord05 (context bar on every screen). Sample names, times and prices are backend data; they are in the strings file only so the six languages can be checked. Consistent sample: home booking 3 items (140) + home fee 25, centre booking MRI 450, estimated insurance share 190, due now 425.

Open: the context bar after booking is shown read-only in spirit (same look); the spec does not say if it stays editable on post-booking screens. Open: the "Emergency" button copy and flow (ambulance call plus alert to Nabd) is a proposal; the spec only names the button. Open: wording of "cash" for self-paid items (the screens say self-paid, since it is paid through Moyasar). Open: how the 5-minute confirmation window and the 24 h approval clock are set (shown as examples). Open: radiology reports (MRI) have no value/range layout; only a pending row is drawn. Open: trend charts keep the data order left to right in RTL (chart convention). Open: the technician photo is drawn as the existing user icon placeholder since no photo asset exists on a board.
