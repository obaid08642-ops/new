## 3. Endpoint wiring summary

Every (route, endpoint) pair found statically. Statuses:
- `OK`: a backend controller (or BFF handler) serves this path and method.
- `WRONG_METHOD`: the path exists but not with this method.
- `NO_ROUTE`: no backend controller serves this path (after stripping `/api/v1`).
- `PROXY_BLOCKED`: web call through `/api/patient/*` that `patient-web/lib/api/patient-allowlist.ts` rejects (the proxy answers 404), checked with a sample UUID for each `:param`.
- `PROXY_BLOCKED?`: as above, but the path has params; it is blocked for a UUID, a slug and every short string literal of the calling file. Confirm with the values the screen really sends.
- `NO_HANDLER`: web call to `/api/*` with no route handler in `patient-web/app/api`.
- `EXTERNAL`: AI service (`EXPO_PUBLIC_AI_URL`), not checked here.
- `PARTIAL`: the path ends in a variable suffix (`${id}${suffix}`); only the prefix is known (shown with `/…`), so it is not checked.
