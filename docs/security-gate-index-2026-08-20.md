# فهرس بوابات الأمن للدفعات المنجزة — Web App نبض بلس

## الغرض وحدود القرار

يوحّد هذا الفهرس أدلة الأمن للدفعات **المنجزة فعلياً** في Web App للمريض حتى 20 أغسطس 2026. وهو لا يحوّل أي عقد Backend ناقص إلى رحلة مكتملة، ولا يعد دليلاً على ميزات غير مبنية. تتبع كل قراءة خاصة النموذج نفسه: جلسة في cookies `httpOnly`، طلب خادمي عبر BFF، تفويض Backend باسم المريض المستخرج من JWT، وallowlist لحقول العرض.

> عند غياب عقد أو اختبار ملكية، يبقى المسار أو الإجراء محجوباً. لا تُستخدم بيانات بديلة ولا زر أو نجاح محلي بديل.

## مصفوفة الأدلة الموحدة

| الدفعة المنجزة | الجلسة والتفويض | BOLA/IDOR والمدخلات | الخصوصية والأخطاء | الملفات/التغيير/الاعتمادات | الدليل والقرار |
|---|---|---|---|---|---|
| نواة المريض والـBFF | cookies `httpOnly` وتجديد واحد مقيد؛ لا `localStorage`. | بوابة المتصفح تقبل `GET` للطلبات المدرجة فقط؛ لا عمليات كتابة. | فشل الاتصال يصير `503 upstream_unavailable` بلا حمولة حساسة. | لا رفع، لا دفع، لا تعديل بيانات. | اختبارات `lib/auth/refresh.test.ts` و`lib/api/upstream.test.ts` واختبارات بوابة المريض؛ صالح للقراءة الموثقة فقط. |
| Sandbox والملكية | تسجيل دخول خادمي وحسابا اختبار معزولان عبر متغيرات البيئة فقط. | مالك الطلب ينجح؛ الحساب الآخر يتلقى `403/404` بحسب العقد. المسارات الذاتية تختبر `401` بلا جلسة. | لا تطبع الاختبارات التوكنات أو كلمات المرور أو أجسام حساسة. | جميع عمليات Sandbox المستخدمة قرائية (`GET`)؛ لا إنشاء أو إلغاء أو دفع أو رفع. | [بوابة Sandbox](./phase-5-sandbox-security-gate.md)؛ صالح لتغطية العقود القرائية ذات الاختبار الحي. |
| تفاصيل الكتالوج المقيدة | الوصول العام لا يحمل Bearer أو cookie مريض. | `medicineId` مقيد بالنمط قبل جلب upstream. | SSR يحجب السعر ومعرّف المريض والملفات؛ لا `Drug` أو ادعاء علاجي. | لا سلة أو checkout أو وصفة أو عملية تغيير. | [بوابة تفاصيل الدواء](./phase-5-public-medicine-detail-security.md)؛ يبقى `noindex` حتى G-SEO-002. |
| اكتشاف المحتوى العام | لا تفتح صفحة عامة جلسة مريض أو API خاص. | لا `patientId` أو معرفات حجوزات في sitemap؛ بحث الكتالوج محدود الإدخال. | robots و`X-Robots-Tag` يعزلان الخاص، وSSR يحجب السعر والبيانات الخاصة. | لا ملفات أو mutations عامة؛ مصدر الكتالوج المختلط غير مؤهل للفهرسة. | [بوابة الاكتشاف](./phase-6-public-discovery-security-gate.md) و`app/seo.test.ts`؛ تقتصر sitemap على اللغات العامة الست. |
| Premium والقوائم والتفاصيل | صفحة الدخول لا تثبت بيانات Sandbox؛ الصفحات الخاصة تمر عبر BFF. | تفاصيل الطلب والموعد والتشخيص تعتمد المعرف المقيد واستجابة حجب؛ تنقل الرجوع لا يفتح موردًا جديدًا. | اختبارات SSR تمنع التوكنات والهوية والأسعار والتقارير؛ الحركة لا توحي بتغير طبي. | لا أزرار حجز أو إلغاء أو رفع أو مكالمة أو صرف غير موثقة. | [بوابة Premium](./phase-7-premium-ui-security-gate.md)؛ صالح للعرض القرائي فقط. |

## قواعد فحص إلزامية للدفعات التالية

لا يكتمل أي مسار جديد أو تغيير حالة قبل توثيق البنود التالية في دليل دفعة مستقل:

| المحور | معيار الإغلاق |
|---|---|
| التفويض | اختبار owner مقابل other عندما يحمل المسار معرف مورد؛ أو إثبات `401` بلا جلسة لمسار ذاتي لا يقبل معرفاً. |
| الجلسة | لا توكن في URL أو HTML أو `localStorage`؛ refresh محدود ولا ينشئ جلسة بديلة عند الفشل. |
| المدخلات | أنماط/طول/صفحات مقيدة قبل upstream، ورفض واضح للمدخل غير الصالح. |
| الملفات | لا رفع أو تنزيل أو URL موقّع قبل عقد MIME/الحجم/العمر/الملكية؛ الحظر المعلن ليس واجهة شكلية. |
| الخصوصية | allowlist DTO واختبار SSR يمنع الحقول الداخلية والهوية والملفات والأسعار حيث لا تكون مصرحاً بها. |
| الأخطاء والسجلات | `401` و`403/404` و`422` و`503` منفصلة؛ لا نجاح بديل ولا طباعة أسرار أو بيانات صحية. |
| الاعتمادات | OpenAPI/DTO/response/error وقيود التشغيل الفعلي متوفرة قبل إظهار العملية؛ النقص يسجل كفجوة Backend. |

## خارج نطاق الإغلاق حالياً

هذا الفهرس لا يغلق الفجوات التي لا تملك عقداً خلفياً أو عملية ملكية قابلة للاختبار: OTP، تفاصيل الرعاية المنزلية، DTO هوية الملف وأسماء العائلة، تفاصيل الوصفات والمحادثات، الرفع وOCR، المكالمات/RTC، وتصنيف الكتالوج المنشور. متطلبات كل منها مسجلة في [حزمة تسليم Backend](./backend-handoff-phase-5.md).

## نتيجة الفهرس

توجد أدلة موحدة للدفعات المنجزة، وتبقى بوابة الأمن العامة **مستمرة**: عند تسليم عقد جديد يجب إضافة صف/دليل واختبارات إليه قبل إغلاق رحلة جديدة. لا يمثل هذا الفهرس تصريحاً بالنشر النهائي أو بالدمج مع `main` الخارجي المتباعد.
