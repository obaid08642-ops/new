# حالة التنفيذ الكامل v2

تم تشغيل نسخة مشتقة كاملة على 21,013 سجلاً. لم يُعدّل المصدر الخام. عولجت المسافات والقوائم والتطابقات الآمنة بين description وMore Information، وأضيف حقل more_information إلى عقد المحتوى لحفظ النص المختلف للمراجعة بدلاً من إسقاطه.

أُعيد تحليل الهوية فظهرت 79 مجموعة تكرار قوية تشمل 159 سجلاً، ولم يُحذف أي سجل. أُرفقت مرشحات التصنيف والـslug لكل 21,013 سجلاً، مع بقاء الاعتماد النهائي مغلقاً.

تم إنشاء إصدار داخلي بم manifests لكل اللغات الست، لكنه يحتوي حالياً على فهارس عامة فارغة لأن جميع أعلام النشر والاعتماد والفهرسة مغلقة. هذا مقصود لحماية المحتوى الطبي.

الترجمة الآلية للغات الأربع لا تُعتمد طبياً. أداة الترجمة المسودة موجودة وقابلة للاستئناف، لكن واجهة النموذج لم تُرجع استجابة أثناء التشغيل الأخير؛ لذلك لم تُسجّل ترجمات مخترعة أو غير قابلة للتدقيق.
