# حالة إكمال العربية والإنجليزية v8 عبر sitemap

## الحكم الصريح

تم تنفيذ مسار بديل كامل لا يعتمد على CAPTCHA: استُخدمت خرائط موقع صيدليات الدواء، وبُنيت شجرة الفئات الرسمية، وطُبّقت إعادة تصنيف منظمة على كامل 20,993 سجل بعد حذف التكرارات المؤكدة. **النسخة v8 مكتملة بنيوياً، وليست مكتملة طبياً للنشر العام.**

لا يجوز وصف البيانات بأنها 100% مكتملة من الناحية الطبية، لأن حقولاً مهمة غائبة أصلاً من المصدر ولم يصبح الجلب الجماعي من API متاحاً بسبب `403/CAPTCHA`، كما أن تشغيل استخراج LLM كامل توقف بسبب عدم توفر رصيد كافٍ. لم تُملأ الحقول الناقصة بالتخمين.

وجود Product ID في sitemap يثبت وجود رابط المنتج في الفهرس الخارجي، لكنه لا يتيح استخراج تفاصيل الصفحة جماعياً من بيئة التنفيذ الحالية؛ الجلب المباشر للـAPI يعيد `403`/CAPTCHA. الحالات الـ149 محفوظة في قائمة استثناءات بالمعرف والاسم وحالة الحقول ولم تُحذف أو تُخفَ.

## التصنيف

أُعيد تصنيف طبقة `العروض` بالكامل؛ العرض ليس Main Category، ولذلك أعيد تحديد الفئة الفعلية لـ1,299 سجلاً وفق أدلة الاسم والوصف. ثم وُحّدت Main Category مع مصطلحات شجرة الموقع الرسمية.

الفئات الرئيسية الموحدة هي: `makeup-and-accessories`، `skin-care`، `hair-care`، `mum-and-baby`، `personal-care`، `medicine-and-treatment`، `vitamins-and-healthy-nutrition`، `home-health-care`، و`other-health`.

## ما يمنع الادعاء بالجاهزية الطبية 100%

النسخة اجتازت كل فحوصات البنية: فريدة المعرفات، فريدة slugs، لا More Information متبقٍ، ولا سجل بلا مستويات taxonomy. لكنها لم تجتز بوابة النشر الطبي للأسباب التالية:

1. عدد كبير من الحقول الطبية غير موجود في المصدر.
2. API المنتج صحيح ومحتواه غني، لكنه غير متاح للجلب الجماعي الحالي بسبب CAPTCHA/403.
3. استخراج الـLLM المنظم لم يُطبّق بسبب عائق القدرة؛ الاستجابة أعادت `Insufficient credits` ولم تُكتب أي بيانات مولّدة في الكتالوج.
4. كل تصنيفات taxonomy ما زالت `proposed/review_required` ولم تتحول إلى اعتماد طبي.

## القرار

يمكن استخدام v8 كنسخة عمل منظمة للتطبيق والويب مع بوابة نشر مغلقة. لا ينبغي بدء ترجمة اللغات الأربع بوصفها نسخة جاهزة للإنتاج الطبي، لأن الترجمة لا تحل فجوات المصدر أو الاعتماد الطبي. عند توفر وصول مصرح للـAPI أو سعة LLM، يمكن استئناف سجل التغطية لكل Product ID دون إعادة الأعمال المنجزة.
