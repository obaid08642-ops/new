# معايير قبول العربية والإنجليزية قبل الترجمة

## مبدأ العمل

كل سجل يجب أن يُراجع على مستوى النص والمعنى، لا عبر كلمات مفتاحية فقط. النصوص التي قد تحمل استخدامات أو جرعات أو تحذيرات أو موانع أو تخزين لا تُحذف إلا بعد نقل المعنى المثبت إلى الحقل الصحيح أو تسجيل سبب الإبقاء/الاستثناء. لا يُنشأ محتوى طبي غير موجود في دليل السجل أو مصدر خارجي موثق.

## معايير القبول الإلزامية

| المعيار | الاختبار | النتيجة المطلوبة |
|---|---|---|
| المعرف | فريدة Product ID | لا تكرار ولا فقد معرف |
| اللغة | وجود اسم عرض عربي وإنجليزي | مكتمل لكل سجل |
| المحتوى المتبقي | تحليل كامل لـMore Information والنصوص المتصلة | قرار موثق لكل سجل: مكرر، موزع، محتفظ به، أو استثناء |
| توزيع المعنى | استخدامات، جرعات، تحذيرات، موانع، تخزين | يضاف فقط عند وجود دليل صريح؛ لا ملء تخميني |
| More Information | بعد توزيع المعنى | لا يزال موجوداً فقط إذا احتوى مادة فريدة لم يقابلها حقل في العقد، مع سبب |
| التصنيف | Main + Sub + Sub-sub | كل سجل يحمل طبقات صالحة ومصدر قرار |
| العروض | فصل طبقة العرض عن طبيعة المنتج | لا يكون العرض Main Category لمنتج فعلي |
| الروابط الخارجية | sitemap/API/pages | توثيق نتيجة المطابقة أو الاستثناء لكل Product ID |
| slugs | فريدة لكل لغة | لا نقص ولا تصادم |
| الحوكمة | محتوى طبي غير مثبت | يبقى غير منشور حتى مراجعة أو مصدر موثق |

## تعريف الجاهزية للترجمة

النسخة **جاهزة للترجمة** عندما تكون عربية وإنجليزية منضبطتين بنيوياً ودلالياً، ويكون لكل سجل نتيجة قرار قابلة للتتبع. لا تعني الجاهزية للترجمة أن الادعاءات الطبية مصدّقة للنشر؛ الترجمة لا تنقل أي حقل طبي لم يثبت مصدره.

## مصادر الدليل وترتيبها

1. نص السجل العربي والإنجليزي الأصلي، بما يشمل `More Information`.
2. API أو صفحة المنتج عند توفر وصول مسموح.
3. sitemap المنتج والفئة لإثبات رابط المنتج وشجرة التصنيف.
4. استثناء موثق بالمعرف والسبب عندما لا يتوفر دليل كافٍ.
