# حالة التحقق غير المتلف على بيئة الإنتاج

## نطاق الأمان

لا توجد بيئة staging مستقلة وفق المعلومات المقدمة. لذلك لا تُنفَّذ في هذه الجولة سوى طلبات `GET` عامة لا تستخدم بيانات الدخول ولا تنشئ سجلات أو تعدّل حالة أو تحفظ كوكيز جلسة. لا تُنسخ بيانات اعتماد الإنتاج أو أوامر وصول البنية التحتية إلى أي ملف أو مستودع.

## نتائج قابلية الوصول

| الوجهة | الفحص | النتيجة | الدلالة |
|---|---|---:|---|
| `https://api.nabd.plus/api/v1` | GET عام | 200 | واجهة NestJS قابلة للوصول وأعلنت الحالة `ok` والإصدار `1.0.0`. |
| `https://api.nabd.plus/api/v1/health` | GET عام | 404 | مسار الصحة المفترض غير منشور بهذا الاسم؛ لا يُعد ذلك فشل خدمة بعد نجاح الجذر. |
| `https://admin.nabd.plus` | GET عام | 200 | واجهة المدير قابلة للوصول علناً حتى صفحة الدخول. |
| `https://provider.nabd.plus` | GET عام | فشل DNS | بوابة الويب المذكورة للمزوّد غير قابلة للوصول من البيئة الحالية؛ يلزم تأكيد العنوان أو إعداد DNS. |

## قرار المرحلة

يمكن متابعة مواءمة خريطة الواجهة مع عقود API ومراجعة المسارات العامة. أما تسجيل الدخول واختبارات الأدوار أو أي طلب `POST` أو `PUT` أو `PATCH` أو `DELETE` فلا تبدأ قبل تصنيف الحالات وموافقة صريحة تحدد العمليات المتلفة المسموح بها في الإنتاج.
