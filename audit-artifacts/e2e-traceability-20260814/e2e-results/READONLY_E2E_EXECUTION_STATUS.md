# حالة تنفيذ E2E غير المتلف

## نطاق التنفيذ

نُفذت جولة محكومة على الإنتاج بعد موافقة محددة لتسجيل الدخول بحسابات sandbox. اقتصر التنفيذ على `POST` لتسجيل الدخول ثم `GET` فقط. لم تُحفظ كلمات مرور أو رموز أو حمولة استجابة أو بيانات صحية، ولم تُنفذ عملية مالية أو موعد أو طلب أو حجز أو إلغاء أو رفع أو تعديل بيانات.

| المؤشر | النتيجة |
|---|---:|
| الأدوار التي حاولت المصادقة | 8 |
| رموز sandbox التي صدرت | 7 |
| بوابات 2FA التي ثبتت | 1 |
| طلبات GET الناجحة المسجلة | 33 |
| عمليات تغيير الحالة المنفذة | 0 |
| تحقق BOLA ذو هويتين | 0 |

## مصفوفة الأدوار

| الدور | المصادقة | تحقق القراءة | القرار |
|---|---|---|---|

| الطبيب | نجحت عبر مسار المزوّد | `/provider/jobs/my-capabilities` و`/provider/jobs/queue`: 200 | اجتاز نطاق عمل المزوّد المحدود. |
| الصيدلي | نجحت عبر مسار المزوّد | مسارا عمل المزوّد: 200 | اجتاز نطاق عمل المزوّد المحدود. |
| المنشأة | نجحت عبر مسار المزوّد | مسارا عمل المزوّد: 200 | اجتاز نطاق عمل المزوّد المحدود. |
| المختبر | نجحت عبر مسار المزوّد | مسارا عمل المزوّد: 200 | اجتاز نطاق عمل المزوّد المحدود. |
| الأشعة | نجحت عبر مسار المزوّد | مسارا عمل المزوّد: 200 | اجتاز نطاق عمل المزوّد المحدود. |
| التمريض المنزلي | نجحت عبر مسار المزوّد | مسارا عمل المزوّد: 200 | اجتاز نطاق عمل المزوّد المحدود. |
| المدير | أعادت بوابة 2FA كما هو متوقع | لا GET؛ لم يُستخدم أو يُطلب رمز OTP | محجوب بصورة صحيحة في هذه الجولة. |

## ملاحظات تحقق العقد

رمز المزوّد الصادر يحمل دوراً عاماً `provider`. قُبل هذا الرمز لمسارات `/provider/jobs/*` لكنه أعاد `401` عند `/auth/me` و`403` عند `/providers/me/profile`، وهي نتيجة تشير إلى عدم توافق عقد واضح بين رمز تطبيق المزوّد وحارس/أدوار مسارات المستخدم العامة. لا يمكن اعتبار هذا اجتيازاً كاملاً لتفويض المزوّد؛ سُجل كعيب عقدي عالي الأولوية.

كما أثبتت جولة GET العامة أن `provider.nabd.plus` لم يحل DNS من بيئة الاختبار، في حين كان API ولوحة المدير متاحين. وتبقى اختبارات المدير بعد 2FA، وتحقيق BOLA بهويتين وموارد منفصلة، وجميع الانتقالات المتلفة معلقة على موافقات منفصلة وتجهيزات اختبارية محددة.
