# Route and contract analysis status

This is the raw route-decorator checkpoint for the required main audit. It records controller, HTTP decorator, and source-line evidence from the extracted `nabdah-backend.zip` source member, plus surface counts for web, mobile, provider, and admin archives.

It is not a final finding list. Each route still requires semantic linkage to service, DTO/schema, auth/role, ownership, state transition, price source, insurance/payment timing, audit/storage, consumer, and tests. A route being present does not prove its journey is complete, and absence from a raw decorator scan does not prove a missing contract.

The source archives are tracked first-party containers in main. Their lack of direct unpacked roots is recorded as a baseline structure fact, not as a missing-feature conclusion.
