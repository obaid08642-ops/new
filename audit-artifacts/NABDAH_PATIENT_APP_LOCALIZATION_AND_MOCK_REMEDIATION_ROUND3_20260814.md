# تقرير تسليم: مراجعة التوطين والبيانات الوهمية — تطبيق المريض

**التاريخ:** 14 أغسطس 2026.
**الفرع المستهدف:** `fix/e2e-operational-contracts-20260814`.
**الحكم:** هذه دفعة معالجة محلية موثقة، وليست إعلان جاهزية للمتاجر أو إثبات اتصال حي.

## النتيجة التنفيذية

تمت مراجعة قاموس الواجهة المؤلف من **3011** مصدر عربي في **151/151** دفعة. تغطي القيم الإنجليزية والأوردية والهندية والبنغالية والفلبينية، وفحص البنية يثبت عدم وجود حقل لغة فارغ أو متغير قالب مفقود. رصدت المراجعة الدلالية 110 تصحيحات؛ طُبق منها **90** بعد تحقق القوالب، واستبعدت 20 قيمة لأنها كيان تأميني يحتاج مصدر بيانات أو قالب/شيفرة يجب إصلاحه في المصدر لا في القاموس.

| مجال التحقق | النتيجة | حد الإثبات |
|---|---|---|
| بنية القاموس | 3011 مفتاحاً × 5 لغات؛ 0 فشل بنيوي | لا تثبت قبولاً لغوياً سريرياً أو مالياً |
| المراجعة الدلالية | 151/151 دفعة؛ 90 تصحيحاً مطبقاً | مراجعة مترجمين أصليين مختصين ما زالت مطلوبة قبل المتاجر |
| توسعة المسار | 46 ملف Text و37 TextInput و53 Alert عبر أغلفة مترجمة؛ `DSText` وقوالب وقت التشغيل مدعومة | لا يثبت التحليل الساكن وحده كل route أو مكوّن خارجي |
| جرد النصوص غير المثبتة | 536 مرشحاً في 142 ملفاً بعد التحسين | المرشح قد يكون خاصية مكوّن مترجم أو بيانات API أو يحتاج قراراً؛ ليس فشلاً مثبتاً لكل سطر |
| الرموز التعبيرية | 0 رمز مرئي في جرد المصدر النهائي | يلزم فحص بصري للأيقونات المتجهية على الأجهزة |
| بناء iOS | `expo export --platform ios` ناجح بعد الدفعة | لا يثبت جهازاً أو خدمات خادم أو دفعاً أو LiveKit |

## معالجة البيانات الوهمية المكتشفة في المراجعة الثانية

أزيلت أو حُجبت تدفقات كانت تعرض مؤشرات صحية أو مالية أو تشغيلية محلية: إعادة صرف الأدوية، نتيجة تغطية التأمين، تتبع الطبيب الحي، التقرير الصحي الشهري، مترجم الوصفات، فاحص الأعراض، مخطط الوجبات، تحليل الصورة الغذائية، مزامنة الأجهزة القابلة للارتداء، والمساعد الصوتي. لا تستبدل هذه الحالات المعطلة وظيفة تشغيلية؛ تعود فقط عند تقديم عقد API/بيانات/RBAC وسياسة سلامة ملائمة ثم اختبارها على staging.

| الحالة | القرار |
|---|---|
| بيانات صحية أو مالية محلية | أزيلت ولم يُعرض بديل رقمي أو نجاح مزعوم |
| خدمة بلا عقد أو بيئة تحقق | حالة عدم إتاحة صريحة مع توثيق العقد المطلوب في السجل الرئيسي |
| placeholders الإرشادية | ليست بيانات وهمية تلقائياً؛ تُترجم عبر الأغلفة أو المكوّنات المشتركة عند ثبوت المسار |
| عشوائية لإنشاء معرفات تقنية أو retry jitter | تبقى خارج نطاق بيانات المستخدم المرئية؛ لا تمثل قراءة صحية أو مالية |

## حدود لا يجوز تجاوزها

لا يمكن الادعاء بأن **كل ملف وكل شاشة وكل زر** مترجم أو مثبت تشغيلياً من هذا العمل وحده. يلزم اختبار يدوي route-by-route لكل لغة ووضع اتجاه على أجهزة iOS وAndroid، واعتماد لغوي طبي/مالي/قانوني، وبيئة staging لعقود التأمين والـOCR والصوت والتتبع وLiveKit والدفع. يبقى lint التاريخي لتطبيق المريض بوابة إصدار غير مغلقة.
