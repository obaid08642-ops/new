# Phase 0B semantic evidence — CartService contract spec

**Baseline:** `main @ 22526bedb77a3d8148219036367e4714f401aecc`

**Member read in full:** `src/modules/cart/cart.contract.spec.ts:1–74`

The spec constructs CartService with mocked cart, medicine, order and user collaborators (`5–19`). It verifies catalog medicine name/price and prescription metadata are used instead of client-controlled values, with quantity two persisted (`21–30`). It verifies an unmatched manual medicine request is stored as pharmacy kind with zero quoted price and pending review (`32–40`), and an unknown catalog medicine produces NotFoundException (`42–45`). It verifies cash checkout uses a patient address and server-owned pharmacy line, creates an order with medicine ID/quantity/address/payment method, returns order state/total, then clears and saves the cart (`47–66`). It verifies unsupported `card-local` is rejected before local order creation (`68–73`).

This provides useful contract-level truthfulness checks for catalog-derived values and manual-item zero quotation. However, all persistence and downstream services are mocked. No HTTP auth/owner-stranger-unauth matrix, cart ID/tenant scope, address ownership or profile state is exercised (`6–19,47–66`). Quantity has no positive/integer/max/stock/duplicate validation; no catalog active/expiry/prescription/safety or inventory reservation is tested (`21–30`). Manual-name content, dosage, prescription upload and review workflow are not covered (`32–40`). Checkout does not test server recomputation of all totals, tax/discount/delivery fee/currency, price changes, stock race, cart version, payment idempotency, order creation failure, rollback/orphaned cart or replay (`47–66`). Only cash and one unsupported payment method are covered; card/insurance/wallet/payment intent and authorization are absent (`47–73`). No PII/address minimization, audit, notification, cache consistency or live DB/payment/inventory evidence exists. No code was changed and no build/test/application operation was performed during this read.
