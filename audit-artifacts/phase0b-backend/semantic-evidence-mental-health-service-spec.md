# Phase 0B semantic evidence — MentalHealthService spec

**Baseline:** `main @ 22526bedb77a3d8148219036367e4714f401aecc`

**Member read in full:** `src/modules/mental-health/mental-health.service.spec.ts:1–96`

The spec constructs MentalHealthService with mocked mood, meditation, breathing and crisis-contact models (`10–38`). It verifies a patient-owned mood record stores explicit mood/notes without inventing energy, stress, sleep or severity (`40–50`). It verifies invalid mood, out-of-range scale, excessive notes, excessive tags and malformed logged_at are rejected (`52–59`). It verifies mood history queries patient_id and rejects windows 0 and 366 (`61–68`). It verifies empty mood statistics are truthful null aggregates rather than reassuring/diagnostic claims (`70–79`). It verifies malformed crisis contact input is rejected without persistence (`81–85`) and crisis contacts are scoped to patient_id without appending hard-coded regional hotline data (`87–95`).

The test is mock-only and calls the service directly; HTTP auth, verified identity, patient state, family/dependent delegation, tenant scope and live persistence are unproven (`10–38,61–95`). Although meditation and breathing models are injected, no meditation/breathing behavior is tested (`17–25,40–95`). Mood validation omits all accepted enum values, scale boundaries/type/NaN/Infinity, timestamp timezone/clock skew, note/tag sanitization, duplicate/replay and concurrent writes (`52–59`). It does not test clinical escalation, self-harm/crisis detection, safety response, human handoff, notification delivery or non-diagnostic copy outside the empty-stat case (`40–79`). Crisis contact coverage omits phone normalization, contact consent/relationship, edit/delete ownership, emergency escalation, redaction and retention (`81–95`). No PHI projection, access audit, deletion/DSAR, rate limit/abuse control, event/cache consistency, transaction or error mapping beyond selected BadRequestException exists. No code was changed and no build/test/application operation was performed during this read.
