The fixed credential is shared across six provider accounts and is written onto pre-existing users when the guard is enabled (`106,123–130`). The script persists synthetic approval, license, rating, review, location and pricing truth; a mistaken environment flag or reused database could contaminate test/prod-like data (`17–96,136–151`). It has no transaction, rollback, per-record audit, conflict handling, dry-run, preflight database-name check or idempotency key; partial failure can leave a mixed dataset (`98–174`).
