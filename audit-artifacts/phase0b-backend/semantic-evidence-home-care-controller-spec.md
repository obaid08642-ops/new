# Phase 0B semantic evidence — NursingController spec

**Baseline:** `main @ 22526bedb77a3d8148219036367e4714f401aecc`

**Member read in full:** `src/modules/home-care/home-care.controller.spec.ts:1–75`

The spec constructs NursingController with mocked booking/service/nurse models, a connection, event emitter and a workflow engine whose apply directly executes mutate (`5–18`). It verifies a patient cannot read another patient visit (`20–25`), a non-nursing provider cannot list nursing visits (`27–32`), an unassigned nursing provider can accept a NEW_REQUEST and have provider_id/state history/workflow transition set (`34–45`), a provider cannot mutate another provider's visit (`47–52`), patients cannot access the provider wallet (`54–59`), wallet data uses booking total_price instead of the legacy 150 amount (`61–67`), and start-care rejects a confirmed booking before arrival without saving (`69–74`).

The suite is direct-controller/mock-bound; guards, HTTP authentication, verified provider identity, tenant/facility boundaries, live Mongo and real workflow transactions are unproven (`6–18,20–74`). Ownership coverage does not test missing/stranger/unauthenticated routes comprehensively, nurse license/credential/branch capability, patient/family delegation or assignment races (`20–52`). Provider acceptance covers one NEW_REQUEST/accept path only; reject, already-assigned, expired/cancelled, concurrent acceptance, schedule conflict, location/arrival verification, cancellation, completion and emergency transitions are absent (`34–45,69–74`). Wallet coverage uses one completed booking and one amount, with no ledger/source-of-truth, currency, fees, taxes, insurance, pending/locked/settled states, pagination or financial reconciliation (`54–67`). GPS/arrival and start-care timing are not validated; workflow mock does not prove CAS/rollback/atomicity (`16,34–45,69–74`). No visit-report/clinical PII projection, signed media, consent, audit, retention/DSAR, idempotency, notifications, events, cache, rate limits or live provider/financial evidence exists. No code was changed and no build/test/application operation was performed during this read.
