# اختبارات التكامل الحية لواجهة المزوّد

تحتوي هذه المجلدات على سيناريوهات تكامل **تتحقق من التخزين وإعادة القراءة الفعلية** لمسارات المزوّد. وهي ليست اختبارات محاكاة، وتقوم بإنشاء وحذف بيانات اختبار؛ لذلك لا يجوز تشغيلها على الإنتاج أو على قاعدة مشتركة مع بيانات مستخدمين.

> يجب توفير البيئة المعزولة صراحةً. لا تعتمد السيناريوهات المحمولة على مسار مستخدم محلي، أو عنوان محلي افتراضي، أو ملف حالة في `/tmp`.

| السيناريو | مجال التحقق |
|---|---|
| `provider-production.js` | قرارات التأمين، CRM، الإحالات، availability، claims، والتقارير الواردة، مع تحقق الملكية وإعادة القراءة. |
| `pharmacy-scenarios.js` | دورة بث الصيدلية والاستجابة الكاملة/الجزئية والرفض والإشعارات. |
| `provider-verticals.js` | دورات المختبر، الأشعة، التمريض، المنشأة، والإسعاف. |

## المتطلبات

يلزم أن يكون الخادم مبنياً ومشغلاً ضد **MongoDB وRedis مخصصين للاختبار فقط**. وتحتاج كل سيناريوهات المزوّد المتنقلة إلى المتغيرات التالية؛ ولا توجد قيم افتراضية لها:

| المتغير | المعنى |
|---|---|
| `BASE` | عنوان API كاملاً متضمناً `/api/v1`، مثال: `https://e2e.example.test/api/v1`. |
| `MONGO_URI` | سلسلة اتصال MongoDB للبيئة المعزولة نفسها. |
| `E2E_DB` | اسم قاعدة اختبار منفصلة تماماً، مثل `nabdah_e2e_20260827`. |
| `E2E_JWT_SECRET` | سر JWT المطابق للخادم في بيئة الاختبار. |
| `E2E_ALLOW_DESTRUCTIVE` | يجب أن تكون قيمته النصية `true` لتأكيد القبول المتعمد لتغيير بيانات الاختبار. |

## التشغيل

بعد توفير البنية المعزولة وبناء الخادم، شغّل كل سيناريو بصورة صريحة من جذر الخادم:

```bash
export BASE='https://e2e.example.test/api/v1'
export MONGO_URI='mongodb://user:password@mongo.example.test:27017'
export E2E_DB='nabdah_e2e_20260827'
export E2E_JWT_SECRET='سر-خاص-ببيئة-الاختبار'
export E2E_ALLOW_DESTRUCTIVE=true

node e2e/provider-production.js
node e2e/pharmacy-scenarios.js
node e2e/provider-verticals.js
```

هذه السيناريوهات تزرع معرفات اختبار مخصصة ثم تنظف مجموعة من آثارها. يجب إنشاء نسخة احتياطية للبيئة التجريبية والتحقق من أن `E2E_DB` ليست قاعدة إنتاج قبل التنفيذ. لا تعتبر نتيجة محلية أو نجاح اختبار وحدة دليلاً على نجاح التكامل الحي؛ يلزم تشغيل الأوامر السابقة مع الخدمات الحقيقية وتسجيل مخرجاتها.

## حدود الأدلة الحالية

الملفات القديمة مثل `boot.js` و`matrix*.js` تبقى مرجعاً تاريخياً ولا تدخل في بوابة الإصدار المحمولة للمزوّد؛ لأنها تفترض منافذ ومسارات وقت تشغيل محلية. كما لا تغطي هذه السيناريوهات وحدها اتصال LiveKit الحقيقي، تخزين الكائنات S3/R2، الإشعارات الفورية على جهاز، تسليم OTP، أو اختبارات Expo على جهاز فعلي.
